
# 🎲 Dice Rolling World Game

A simple, interactive, and beginner-friendly command-line dice rolling game written in **Python**. Roll as many dice as you want, validate user inputs seamlessly, and enjoy an endless rolling session!

---

## ✨ Features

* **Customizable Dice Count:** Choose exactly how many dice you want to roll in each round.
* **Input Validation:** Handles invalid choices gracefully (both for rolling decisions and dice counts).
* **Interactive Loop:** Keep playing as many rounds as you want without restarting the program.
* **Clean Console Interface:** Styled output with clear prompts and friendly feedback.

---
